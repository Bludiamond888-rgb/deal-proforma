# Deal Pro Forma

One-page multifamily back-of-the-envelope (BOE) underwriting PWA for Chairman.

Methodology inspired by public Tactica RES tutorials (Ike Hoffman). Original UI and formulas — not a copy of Tactica Excel files or branding.

## Stack

React + TypeScript + Vite (`base: './'`), versioned service worker, GitHub Pages–ready (`.nojekyll`).

## Develop

```bash
npm install
npm test
npm run dev
npm run build
npm run screens   # Playwright WebKit 440×956 @3 → screens/
```

## Publish

Do **not** push until Chairman approves screenshots via the Publish widget.
